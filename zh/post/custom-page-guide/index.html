自定义页面配置与使用指南

LL a
438 words 7 mins
详细介绍如何在 Hugo Theme Fluid 中创建和配置自定义页面，包括文档页、社群页等

Hugo Theme Fluid 支持创建各种自定义页面，如文档页、社群页、服务条款页等。本文将详细介绍如何配置和使用自定义页面功能。

什么是自定义页面？

自定义页面是独立于博客文章的特殊页面，通常用于：

  • 📄 文档说明页
  • 👥 社群/团队介绍页
  • 📋 服务条款页
  • 🔒 隐私政策页
  • 📞 联系我们页
  • 🎯 项目展示页

快速创建

方法一：使用 Hugo 命令

hugo new page/my-page.md

这会在 content/page/ 目录下创建一个新页面，使用主题提供的 archetypes/page.md 模板。

方法二：手动创建

在 content/ 目录下创建 Markdown 文件：

content/
├── docs.md           # 文档页
├── community.md      # 社群页
├── terms.md          # 服务条款
└── privacy.md        # 隐私政策

页面配置

基础 Front Matter

---
title: "页面标题"
subtitle: "页面副标题（可选）"
date: 2024-12-24
layout: "page"
---

完整配置示例

---
title: "文档中心"
subtitle: "Hugo Theme Fluid 使用文档"
date: 2024-12-24
layout: "page"

# Banner 配置
banner_img: "/img/docs-banner.jpg"
banner_img_height: 60
banner_mask_alpha: 0.3

# 功能开关
comments: true      # 启用评论
math: true          # 启用数学公式
mermaid: true       # 启用 Mermaid 图表
image_zoom: true    # 启用图片放大（默认开启）
---

配置参数详解

Banner 配置

参数类型默认值说明
banner_imgstring主题默认图Banner 背景图片
banner_img_heightnumber70Banner 高度百分比
banner_mask_alphanumber0.3蒙版透明度 (0-1)

功能开关

参数类型默认值说明
commentsbooleanfalse是否启用评论
mathbooleanfalse是否启用数学公式
mermaidbooleanfalse是否启用 Mermaid 图表
image_zoombooleantrue是否启用图片放大

添加到导航菜单

在 config/_default/menus.toml 中添加菜单项：

[[main]]
name = "文档"
url = "/docs/"
weight = 50

[[main]]
name = "社群"
url = "/community/"
weight = 60

全局默认配置

在 config/_default/params.toml 中可以设置页面的全局默认值：

[page]
banner_img = "/img/default-page-banner.jpg"
banner_img_height = 70
banner_mask_alpha = 0.3

与文章页的区别

特性自定义页面文章页
布局pagepost
目录无有 TOC
分类/标签无有
上下篇导航无有
评论可选默认开启
列表显示不显示显示在首页

最佳实践

1. 合理组织目录结构

content/
├── post/           # 博客文章
├── page/           # 自定义页面（推荐）
│   ├── docs.md
│   └── terms.md
├── about/          # 关于页面
└── links/          # 友链页面

2. 使用有意义的 URL

---
title: "服务条款"
url: "/terms-of-service/"
---

3. 配置合适的 Banner

  • 选择与页面内容相关的图片
  • 调整蒙版透明度确保标题可读
  • 考虑使用较低的 Banner 高度

4. 按需启用功能

  • 只在需要时启用 math 和 mermaid
  • 这些功能会加载额外的 JS 库

常见问题

Q: 自定义页面会出现在首页文章列表吗？

不会。自定义页面使用 page 布局，不会出现在文章列表中。

Q: 如何让页面出现在导航栏？

在 menus.toml 中添加对应的菜单项即可。

Q: 可以给自定义页面添加评论吗？

可以，在 Front Matter 中设置 comments: true。

Q: 如何创建多级文档？

可以使用 Hugo 的 Section 功能：

content/
└── docs/
    ├── _index.md       # 文档首页
    ├── getting-started.md
    └── configuration.md

总结

Hugo Theme Fluid 的自定义页面功能让你可以轻松创建各种独立页面：

  • ✅ 简单的 Front Matter 配置
  • ✅ 支持数学公式和流程图
  • ✅ 可选的评论功能
  • ✅ 灵活的 Banner 配置
  • ✅ 图片放大和锚点链接
