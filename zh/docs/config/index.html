配置指南

本页面详细介绍 Hugo Fluid 主题的各项配置选项。

基础配置

Hugo 配置 (hugo.toml)

baseURL = "https://example.com/"
title = "我的博客"
theme = "hugo-theme-fluid"

# 默认语言
defaultContentLanguage = "zh"
defaultContentLanguageInSubdir = false

# CJK 语言支持
hasCJKLanguage = true

# 输出格式
[outputs]
home = ["HTML", "RSS", "JSON"]
section = ["HTML", "RSS"]
taxonomy = ["HTML"]
term = ["HTML"]

菜单配置

主菜单 (menus.zh.toml)

Hugo Fluid 主题支持普通菜单项和下拉菜单。菜单配置文件位于 config/_default/menus.zh.toml（中文）、menus.en.toml（英文）、menus.tw.toml（繁体中文）。

普通菜单项

[[main]]
name = "首页"
url = "/"
weight = 1
pre = "iconfont icon-home-fill"

[[main]]
name = "归档"
url = "/archives/"
weight = 2
pre = "iconfont icon-archive-fill"

下拉菜单配置

下拉菜单需要一个父菜单项和多个子菜单项。父菜单项使用 hasChildren = true 标识，子菜单项使用 parent 属性指向父菜单。

# 父菜单项 - 文档下拉菜单
[[main]]
name = "文档"
url = "/docs/"
weight = 7
pre = "iconfont icon-books"
hasChildren = true  # 标识这是一个下拉菜单

# 子菜单项 1
[[main]]
name = "快速开始"
url = "/docs/"
weight = 71
parent = "文档"  # 指向父菜单的 name

# 子菜单项 2
[[main]]
name = "配置指南"
url = "/docs/config/"
weight = 72
parent = "文档"

# 子菜单项 3
[[main]]
name = "主题特性"
url = "/docs/features/"
weight = 73
parent = "文档"

菜单参数说明

参数说明示例
name菜单显示名称"首页"
url链接地址"/" 或 "https://example.com"
weight排序权重（数字越小越靠前）1, 2, 3
pre图标类名"iconfont icon-home-fill"
post链接打开方式"_blank"（新标签页）
hasChildren是否为下拉菜单父项true
parent父菜单名称（仅子菜单项使用）"文档"

外部链接配置

如果要链接到外部网站并在新标签页打开：

[[main]]
name = "GitHub"
url = "https://github.com/ouraihub-hugo-themes/hugo-theme-fluid-dist"
weight = 8
pre = "iconfont icon-github"
post = "_blank"  # 在新标签页打开

下拉菜单外部链接

下拉菜单也可以包含外部链接：

# 父菜单项
[[main]]
name = "链接"
url = "#"
weight = 9
pre = "iconfont icon-link"
hasChildren = true

# 外部链接子项
[[main]]
name = "官方文档"
url = "https://gohugo.io/documentation/"
weight = 91
parent = "链接"
post = "_blank"

# 内部链接子项
[[main]]
name = "友情链接"
url = "/links/"
weight = 92
parent = "链接"

权重排序规则

  • 主菜单项权重：1-10（推荐间隔为 1）
  • 子菜单项权重：父菜单权重 × 10 + 序号
    • 例如：父菜单权重为 7，子菜单权重为 71、72、73

图标配置

主题使用 iconfont 图标库，常用图标类名：

# 常用图标
pre = "iconfont icon-home-fill"      # 首页
pre = "iconfont icon-archive-fill"   # 归档
pre = "iconfont icon-category-fill"  # 分类
pre = "iconfont icon-tags-fill"      # 标签
pre = "iconfont icon-link-fill"      # 友链
pre = "iconfont icon-user-fill"      # 关于
pre = "iconfont icon-books"          # 文档
pre = "iconfont icon-github"         # GitHub
pre = "iconfont icon-search"         # 搜索

多语言菜单

不同语言的菜单配置文件：

  • menus.zh.toml - 简体中文菜单
  • menus.en.toml - 英文菜单
  • menus.tw.toml - 繁体中文菜单

每个语言文件的结构相同，只需要翻译 name 字段：

# menus.en.toml
[[main]]
name = "Docs"           # 英文名称
url = "/docs/"
weight = 7
pre = "iconfont icon-books"
hasChildren = true

[[main]]
name = "Quick Start"    # 英文名称
url = "/docs/"
weight = 71
parent = "Docs"         # 对应英文父菜单名

下拉菜单示例

[[main]] name = “文档” url = “/docs/” weight = 7 pre = “iconfont icon-books” hasChildren = true

[[main]] name = “快速开始” url = “/docs/” weight = 71 parent = “文档”

常见问题

如何自定义 Banner 图片？

在页面的 Front Matter 中设置：

---
title: "我的文章"
banner_img: "/img/my-banner.jpg"
banner_img_height: 70
banner_mask_alpha: 0.3
---

如何禁用某个页面的功能？

在页面的 Front Matter 中设置：

---
title: "我的文章"
toc: false          # 禁用目录
comments: false     # 禁用评论
copyright: false    # 禁用版权声明
---

如何添加自定义页面？

  1. 创建页面文件：
hugo new page/my-page.md
  1. 在菜单中添加链接：
[[main]]
name = "我的页面"
url = "/page/my-page/"
weight = 10

更多配置选项请参考 主题特性 页面。
