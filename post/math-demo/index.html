Math Formula Guide

LL a
327 words 5 mins
A detailed guide to Hugo Fluid theme's math formula features, including MathJax and KaTeX configuration, LaTeX syntax, and rich formula examples.

This article details Hugo Fluid theme’s math formula features, including configuration, syntax, and examples.

Quick Start

1. Enable Math Formulas

Enable math formula support in params.toml:

[post.math]
enable = true
specific = false  # Set to true to enable per-article
engine = "mathjax"  # Options: mathjax or katex

2. Use in Articles

If specific = true, add to article Front-matter:

---
title: "My Article"
math: true
---

Basic Syntax

Inline Formulas

Use single dollar signs $...$ for inline formulas:

SyntaxResult
$E = mc^2$$E = mc^2$
$a^2 + b^2 = c^2$$a^2 + b^2 = c^2$
$\sqrt{x^2 + y^2}$$\sqrt{x^2 + y^2}$

Block Formulas

Use double dollar signs for block formulas:

$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $

Summation, Integration & Limits

Summation

$ \sum_{i=1}^{n} i = \frac{n(n+1)}{2} $

Integration

$ \int_0^{\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2} $

Limits

$ \lim_{x \to 0} \frac{\sin x}{x} = 1 $

Classic Formula Examples

Euler’s Formula

$ e^{i\pi} + 1 = 0 $

Taylor Expansion

$ e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} $

Maxwell’s Equations

$ \begin{aligned} \nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0} \ \nabla \cdot \mathbf{B} &= 0 \end{aligned} $

Engine Comparison

MathJax

Pros:

  • Most comprehensive, supports almost all LaTeX commands
  • High rendering quality
  • Right-click menu support

Cons:

  • Slower loading
  • Larger file size

KaTeX

Pros:

  • Extremely fast rendering
  • Small file size

Cons:

  • Fewer supported LaTeX commands
  • Some complex formulas may not render
