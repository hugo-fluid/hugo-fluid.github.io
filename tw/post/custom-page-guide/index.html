自訂頁面配置與使用指南

LL a
304 words 5 mins
詳細介紹如何在 Hugo Theme Fluid 中建立和配置自訂頁面，包括文件頁、社群頁等

Hugo Theme Fluid 支援建立各種自訂頁面，如文件頁、社群頁、服務條款頁等。本文將詳細介紹如何配置和使用自訂頁面功能。

什麼是自訂頁面？

自訂頁面是獨立於部落格文章的特殊頁面，通常用於：

  • 📄 文件說明頁
  • 👥 社群/團隊介紹頁
  • 📋 服務條款頁
  • 🔒 隱私政策頁
  • 📞 聯絡我們頁
  • 🎯 專案展示頁

快速建立

方法一：使用 Hugo 命令

hugo new page/my-page.md

這會在 content/page/ 目錄下建立一個新頁面，使用主題提供的 archetypes/page.md 模板。

方法二：手動建立

在 content/ 目錄下建立 Markdown 檔案：

content/
├── docs.md           # 文件頁
├── community.md      # 社群頁
├── terms.md          # 服務條款
└── privacy.md        # 隱私政策

頁面配置

基礎 Front Matter

---
title: "頁面標題"
subtitle: "頁面副標題（可選）"
date: 2024-12-24
layout: "page"
---

完整配置範例

---
title: "文件中心"
subtitle: "Hugo Theme Fluid 使用文件"
date: 2024-12-24
layout: "page"

# Banner 配置
banner_img: "/img/docs-banner.jpg"
banner_img_height: 60
banner_mask_alpha: 0.3

# 功能開關
comments: true      # 啟用評論
math: true          # 啟用數學公式
mermaid: true       # 啟用 Mermaid 圖表
image_zoom: true    # 啟用圖片放大（預設開啟）
---

配置參數詳解

Banner 配置

參數類型預設值說明
banner_imgstring主題預設圖Banner 背景圖片
banner_img_heightnumber70Banner 高度百分比
banner_mask_alphanumber0.3蒙版透明度 (0-1)

功能開關

參數類型預設值說明
commentsbooleanfalse是否啟用評論
mathbooleanfalse是否啟用數學公式
mermaidbooleanfalse是否啟用 Mermaid 圖表
image_zoombooleantrue是否啟用圖片放大

新增到導覽選單

在 config/_default/menus.toml 中新增選單項：

[[main]]
name = "文件"
url = "/docs/"
weight = 50

[[main]]
name = "社群"
url = "/community/"
weight = 60

與文章頁的區別

特性自訂頁面文章頁
佈局pagepost
目錄無有 TOC
分類/標籤無有
上下篇導覽無有
評論可選預設開啟
列表顯示不顯示顯示在首頁

最佳實踐

1. 合理組織目錄結構

content/
├── post/           # 部落格文章
├── page/           # 自訂頁面（推薦）
│   ├── docs.md
│   └── terms.md
├── about/          # 關於頁面
└── links/          # 友鏈頁面

2. 使用有意義的 URL

---
title: "服務條款"
url: "/terms-of-service/"
---

總結

Hugo Theme Fluid 的自訂頁面功能讓你可以輕鬆建立各種獨立頁面：

  • ✅ 簡單的 Front Matter 配置
  • ✅ 支援數學公式和流程圖
  • ✅ 可選的評論功能
  • ✅ 靈活的 Banner 配置
  • ✅ 圖片放大和錨點連結
