Mermaid 流程圖使用指南

LL a
247 words 4 mins
詳細介紹 Hugo Fluid 主題的 Mermaid 流程圖功能，包括配置方法、語法說明和豐富的圖表範例。

本文詳細介紹 Hugo Fluid 主題的 Mermaid 流程圖功能。

快速開始

1. 啟用 Mermaid

在 params.toml 中啟用 Mermaid 支援：

[post.mermaid]
enable = true
specific = true
[post.mermaid.options]
theme = "default"

2. 在文章中使用

如果 specific = true，需要在文章的 Front-matter 中添加：

---
title: "我的文章"
mermaid: true
---

基礎流程圖

graph TD

    B -->|是| C[執行操作A]

    C --> E[結束]
    D --> E

graph LR

時序圖 (Sequence Diagram)

sequenceDiagram
    participant 使用者
    participant 瀏覽器
    participant 伺服器
    
    使用者->>瀏覽器: 輸入網址
    瀏覽器->>伺服器: HTTP 請求
    伺服器-->>瀏覽器: HTTP 回應
    瀏覽器-->>使用者: 顯示頁面

類別圖 (Class Diagram)

classDiagram

        +int age

stateDiagram-v2

    section 開發階段
