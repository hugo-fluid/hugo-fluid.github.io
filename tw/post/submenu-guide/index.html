導覽列子選單配置指南

LL a
370 words 6 mins
詳細介紹如何在 Hugo Theme Fluid 中配置導覽列下拉子選單

Hugo Theme Fluid 支援導覽列下拉子選單功能，讓你可以更好地組織導覽連結。本文將詳細介紹如何配置和使用子選單功能。

功能特性

  • 📂 支援多級下拉選單
  • 🖱️ 桌面端懸浮顯示
  • 📱 行動端點擊展開
  • 🎨 平滑動畫效果
  • ♿ 完整的無障礙支援

配置方法

基本配置

在 config/_default/menus.toml 中配置子選單：

# 父選單項（不需要 url，只需要 identifier）
[[main]]
name = "文件"
weight = 7
pre = "iconfont icon-books"
identifier = "docs"

# 子選單項（使用 parent 指向父選單的 identifier）
[[main]]
name = "配置指南"
url = "https://hexo.fluid-dev.com/docs/guide/"
weight = 1
parent = "docs"

[[main]]
name = "圖示用法"
url = "https://hexo.fluid-dev.com/docs/icon/"
weight = 2
parent = "docs"

配置說明

參數說明範例
name選單顯示名稱"文件"
url連結地址（父選單可省略）"/docs/"
weight排序權重7
pre圖示類名"iconfont icon-books"
identifier父選單標識符"docs"
parent子選單指向的父選單標識符"docs"
post連結開啟方式"_blank"

完整範例

# Hugo Theme Fluid - Menu Configuration

# 普通選單項
[[main]]
name = "首頁"
url = "/"
weight = 1
pre = "iconfont icon-home-fill"

[[main]]
name = "歸檔"
url = "/archives/"
weight = 2
pre = "iconfont icon-archive-fill"

# 帶子選單的選單項
[[main]]
name = "分類"
weight = 3
pre = "iconfont icon-category-fill"
identifier = "categories"

[[main]]
name = "技術"
url = "/categories/技術/"
weight = 1
parent = "categories"

[[main]]
name = "生活"
url = "/categories/生活/"
weight = 2
parent = "categories"

[[main]]
name = "教學"
url = "/categories/教學/"
weight = 3
parent = "categories"

# 外部連結子選單
[[main]]
name = "資源"
weight = 8
pre = "iconfont icon-link"
identifier = "resources"

[[main]]
name = "Hugo 官網"
url = "https://gohugo.io/"
weight = 1
parent = "resources"
post = "_blank"

[[main]]
name = "Fluid 文件"
url = "https://hexo.fluid-dev.com/docs/"
weight = 2
parent = "resources"
post = "_blank"

互動行為

桌面端（≥992px）

  • 懸浮觸發 - 滑鼠懸浮在父選單上時自動顯示下拉選單
  • 點擊跳轉 - 點擊子選單項跳轉到對應連結
  • 自動隱藏 - 滑鼠移開後下拉選單自動隱藏

行動端（<992px）

  • 點擊展開 - 點擊父選單項展開/收起下拉選單
  • 箭頭指示 - 下拉箭頭旋轉指示展開狀態
  • 點擊跳轉 - 點擊子選單項跳轉到對應連結
  • 自動收起 - 點擊其他區域或切換選單時自動收起

樣式自訂

CSS 變數

/* 下拉選單背景 */
.navbar .dropdown-menu {
  background-color: rgb(0 0 0 / 30%);
}

/* 下拉選單項顏色 */
.navbar .dropdown-item {
  color: var(--navbar-text-color);
}

/* 懸浮效果 */
.navbar .dropdown-item:hover {
  color: var(--link-hover-color);
  background-color: rgb(0 0 0 / 10%);
}

無障礙支援

子選單元件包含完整的無障礙支援：

  • role="button" - 標識可點擊元素
  • aria-haspopup="true" - 標識有彈出選單
  • aria-expanded - 動態更新展開狀態
  • aria-labelledby - 關聯選單標籤

常見問題

Q: 如何讓父選單也可點擊跳轉？

父選單預設不可點擊（href="javascript:;"），如果需要點擊跳轉，可以新增 url 參數，但這會影響行動端的展開體驗。

Q: 子選單可以巢狀嗎？

目前只支援一級子選單，不支援多級巢狀。

Q: 如何在新視窗開啟連結？

使用 post = "_blank" 參數：

[[main]]
name = "外部連結"
url = "https://example.com"
parent = "resources"
post = "_blank"

最佳實踐

  1. 合理分組 - 將相關連結組織在同一個子選單下
  2. 控制數量 - 每個子選單建議不超過 5-7 個項目
  3. 清晰命名 - 使用簡潔明瞭的選單名稱
  4. 圖示輔助 - 適當使用圖示增強可識別性
  5. 行動優先 - 測試行動端的展開/收起體驗

總結

導覽列子選單功能讓你可以更好地組織網站導覽，提供更清晰的資訊架構。透過簡單的配置，即可實現：

  • 多級選單結構
  • 響應式互動
  • 平滑動畫效果
  • 完整的無障礙支援

希望這篇教學能幫助你配置出理想的導覽選單！
